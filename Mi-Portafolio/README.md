# Mi portafolio

Portafolio personal hecho con HTML y CSS, publicado con GitHub y Vercel.

## Estructura

```
mi-portafolio/
├── index.html    Página principal
├── styles.css    Estilos
├── foto.jpg      Foto de perfil
└── README.md     Este archivo
```

## Qué debes personalizar

1. En `index.html`, reemplaza **Tu Nombre**, **Tu Apellido** y los textos entre corchetes `[ ]`.
2. Cambia los enlaces de correo, LinkedIn y GitHub por los tuyos.
3. Edita o borra los bloques de proyectos según lo que hayas hecho.
4. Si quieres otra foto, reemplaza `foto.jpg` con una imagen cuadrada del mismo nombre.
5. Los colores están al inicio de `styles.css`, en la sección `:root`.

## Ver el sitio en tu computadora

Abre `index.html` con doble clic, o usa la extensión Live Server en VS Code.

## Publicar y actualizar

1. Haz commit de tus cambios en VS Code.
2. Haz clic en **Sync Changes**.
3. Vercel detecta el cambio y vuelve a publicar el sitio automáticamente.
